# Starter Paragraphs composition

This bundled recipe applies the starter content defaults and the public Sous
Paragraphs host, then attaches its shared `field_content` storage to Frontpage.
Both Page and Frontpage keep editable Body text alongside the Image, Text,
Text with Media and Video components. Their Content tabs contain both fields.

The public companion remains responsible for reusable Paragraph types and the
Page host. This small starter layer supplies the Frontpage composition without
changing that repository. It does not migrate older `field_content_body` data;
existing sites must review their field names and explicit upgrade plan.
